1. Project Overview & Objectives

The KTU MCQ Platform is a full-stack web application designed to help students prepare for university exams by taking timed MCQ assessments aligned with KTU S6 Computer Science & Technology (CST) syllabus.

Core Objectives

  • Adaptive Assessment: Timed MCQ tests with server-enforced timers and auto-submission
  • Multi-Role Access: Student, Faculty, and Admin dashboards with distinct workflows
  • Real-Time Analytics: Post-exam mistake classification, accuracy tracking, and exam readiness scoring
  • Automated Difficulty Indexing: Question difficulty auto-adjusts based on student performance data
  • Bulk Question Import: Faculty can bulk-import questions via CSV files
  • Anti-Cheating: Tab-switch detection, server-side timer validation, and answer locking
  • Leaderboard: Global student ranking by accuracy and tests completed

Target Users

Role Capabilities
Student Take tests, view scores, track syllabus mastery, view leaderboard, upload profile picture
Faculty View class performance, create/edit/delete questions, bulk CSV import, download marks CSV
Admin Create & manage tests, full question bank CRUD, platform administration

8. Authentication & Security

  • Authentication Method: JWT (JSON Web Token) — Bearer token in Authorization header
  • Password Hashing: bcryptjs with salt rounds for secure password storage
  • Token Payload: { id, role } — used for route-level authorization
  • Frontend Persistence: Token & user object stored in localStorage
  • Route Protection: ProtectedRoute component checks token presence & role match
  • Anti-Cheating: Tab-switch detection via visibilitychange event with alerts
  • Timer Integrity: Server-issued start_time and duration — client cannot manipulate exam duration
  • Answer Immutability: is_locked flag on answer logs prevents post-submission tampering

9. Analytics Engine

The analyticsEngine.js service runs automatically upon exam completion and performs:

Mistake Classification Matrix

Mistake Type Detection Rule
Guessing Incorrect answer + time spent < 10 seconds
Time Pressure No option selected (null/skipped)
Conceptual Incorrect answer + time spent > 60 seconds
Calculation Incorrect answer + 10-60 seconds (default)

Automated Difficulty Indexing

After ≥5 attempts on a question, difficulty auto-adjusts:

  • Historical accuracy ≥ 70% → Easy
  • Historical accuracy ≤ 40% → Hard
  • Otherwise → Medium

Readiness Status Classification

  • Exam-Ready: Overall accuracy ≥ 75% AND zero conceptual errors
  • Borderline: Overall accuracy ≥ 50% AND guessing errors < 3
  • Not Exam-Ready: All other cases
